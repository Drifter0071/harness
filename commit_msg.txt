fix(state): make AppState Clone so HCI can share the managed instance

The previous attempt wrapped AppState in Arc before app.manage(),
which broke the State<'_, AppState> extractor used by every Tauri
command (error: "state not managed for field state on command
list_saved_models").

Fix: derive Clone on AppState and wrap the inner Mutex fields in
Arc so the struct itself can be cloned. setup() calls .clone() and
passes the original to app.manage() and the clone to HCI. Both
references share the same underlying mutex/dashmap data because the
fields are Arc-wrapped.

No more ptr::read, no UB, no missing-state errors.
